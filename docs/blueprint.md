# **App Name**: ExpenseWise

## Core Features:

- Add Expense: Instantly record expenses to Firestore with auto-timestamping, category selection, and description fields.
- View Expenses: Display expenses in a real-time list; includes edit/delete functionality for data correction and filtering options.
- Monthly Budgeting: Allows users to set a monthly budget and track their spending progress against it using a visual progress bar.
- AI-Powered Budget Prediction: Calculates real-time average daily spend and predicts the exact day and amount the user will exceed their set monthly budget. Tool includes daily spending analysis.
- Personalized Savings Suggestions: Implements the Potential Savings Identifier to suggest a quantifiable reduction target (e.g., 10%) in the user's highest spending category.
- Spending Pattern Analysis: Analyze spending patterns to identify key spending areas. Tool provides insights to encourage balanced spending.
- Trend Forecast: Compare expenses over recent periods to forecast spending trends.

## Style Guidelines:

- Primary color: A calm teal (#4db6ac), symbolizing balance and financial wellness.
- Background color: Soft, light gray (#f0f0f0), provides a clean and unobtrusive backdrop.
- Accent color: Warm orange (#ff8a65), highlighting calls to action.
- Body and headline font: 'Inter', a sans-serif font, provides readability and a modern feel.
- Use minimalist icons for expense categories to aid visual navigation.
- Design a clean, intuitive dashboard displaying expenses and financial insights.
- Incorporate subtle transitions to indicate new data entries and update financial reports.
- Technology: Built using React and Tailwind CSS for a responsive and mobile-first Single Page Application (SPA).
- Data Persistence: Uses Firebase Firestore for secure, real-time, and persistent storage of user expenses and settings.
- Aesthetics: Utilizes a clean, dashboard layout with a professional color palette (e.g., Indigo/Teal accents) and rounded corners for all cards and inputs.
- UX Focus: Prioritizes a clutter-free, card-based design that clearly highlights warnings and smart insights to encourage positive financial habits.
