# 💰 Expensio
**A smart, modern way to manage your personal finances.**

Expensio helps users track daily spending, monitor budgets, and improve financial habits with a clean, responsive interface.

---

## 📌 Overview
Managing daily expenses shouldn't be a chore. **Expensio** allows you to set monthly budgets, log expenses, and see your financial health in real-time. Everything is synced securely to the cloud using Firebase.

---

## ✨ Features
* **Full CRUD**: Add, view, and delete expenses effortlessly.
* **Budget Management**: Set monthly limits and track your progress.
* **Live Calculations**: Automatic remaining balance and total spend updates.
* **Cloud Sync**: Data is stored securely in Firebase Firestore.
* **Modern Auth**: Secure user login via Firebase Authentication.
* **Responsive UI**: Optimized for mobile and desktop using Tailwind CSS & Shadcn/UI.

---

| **Shadcn/UI** | |

---

## ⚙️ How It Works
1. **Auth**: Secure login via Firebase.
2. **Budgeting**: User sets a target monthly budget.
3. **Tracking**: User logs expenses (amount, category, description).
4. **Processing**: Data is synced to Firestore and calculated locally for instant feedback.
